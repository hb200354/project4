[GO-MONTH 실행 방법 (VS Code 확장팩 기준)]

================================
1. 필수 VS Code 확장팩
================================

아래 확장팩 설치

1) Java Extension Pack
   (Microsoft)

2) Spring Boot Extension Pack
   (VMware)

================================
2. 프로젝트 열기
================================

VS Code → File → Open Folder

아래 폴더 열기

project4/spring/gomonth

(pom.xml 이 있는 폴더)

================================
3. Spring Boot Dashboard 열기
================================

1) 키보드에서
   Ctrl + Shift + P

2) 명령어 입력창에
   Spring Boot Dashboard 입력

3) Spring Boot Dashboard: Connect 선택

→ VS Code 좌측 사이드바에
  Spring Boot Dashboard 표시됨

================================
4. 서버 실행 (터미널 사용 X)
================================

방법 1 (권장)

1) VS Code 좌측 메뉴에서
   Spring Boot Dashboard 클릭

2) APPS 목록에서
   gomonth 선택

3) ▶ Run 버튼 클릭

--------------------------------

방법 2

1) GomonthApplication.java 파일 열기

2) 코드 상단 또는 우측의
   ▶ Run Java 클릭

================================
5. 접속 주소
================================

브라우저에서 접속

http://localhost:8080/

GO-MONTH 메인 페이지 출력

변경내용 있으면
저장 후 브라우저에서 Ctrl + F5 새로고침

================================
[끝]
